> 후속: plan 12(RAG 인용·스트리밍)의 답변 렌더를 마크다운으로 바꾼다. 현재는 답변을 평문(`[n]`만 분리)으로 그린다.
> 라이브러리: `react-markdown`(^10)과 `remark-gfm`(^4)이 이미 설치돼 있어 새 의존성이 필요 없다. 부분(미완성) 마크다운도 무난히 렌더해 스트리밍에 적합하다. `original-viewer-dialog`가 같은 조합을 이미 쓴다.

## A. 공유 마크다운 뷰어
- [x] A1 공유 뷰어 컴포넌트(예: `components/drive/markdown-view.tsx`)가 `react-markdown` + `remark-gfm`으로 마크다운을 렌더한다.
- [x] A2 뷰어가 `original-viewer-dialog`와 같은 prose 스타일(제목·목록·표·코드)을 공유한다.
- [x] A3 스트리밍 중 답변과 완료 답변이 모두 이 한 뷰어를 쓴다(렌더 일관성).

## B. 프로토타입
- [x] B1 `app/design/rag-streaming` 프로토타입이 공유 마크다운 뷰어를 부착해 스트리밍·완료 단계를 시안화한다.
- [x] B2 프로토타입이 예시 답변(굵게·번호 목록·중첩 항목·`[n]` 인용)을 마크다운으로 렌더한다.
- [x] B3 사용자가 프로토타입을 승인하기 전에는 C(실제 화면 적용)에 착수하지 않는다.

- [x] C2 `RagAnswer`의 완료 답변이 같은 마크다운 뷰어로 렌더한다(평문 렌더 제거).

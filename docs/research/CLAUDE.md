# Writing a Research Document

- One document covers one topic.
- State conclusions first, then evidence.
- Follow `example.md`.
- Write a one-line question or scope below `# Title`.
- Documents in the same series may share an `NN.` prefix.
- Cite external sources.
- Keep prose terse. One idea per bullet.
- Use bullets or `###`. Do not use `—`, `·`, or `→` chains.
- `## n.` and `### n.m` are stable cross-ref IDs (`§n`). Never renumber. Append only.
- Prefer lists over Mermaid. SQL/bash code blocks are content.
- Avoid excessive Markdown emphasis. No emojis.
- Define common terms once in `docs/glossary.md`.
- Cross-reference related docs with `[00 §1.2]`.
- Do not over-compress. Remove redundancy, not facts.

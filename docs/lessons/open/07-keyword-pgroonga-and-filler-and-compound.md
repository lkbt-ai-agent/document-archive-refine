# Problem

붙여 쓴 복합어로 키워드 검색을 하면 정답 문서를 못 찾고 0건을 낸다.

- 최근 run(`20260705T165354`) 키워드 실패는 `F5-loan-spacing-001` "중소기업정책자금 융자계획" 1건이다. 결과 청크 0건, 문서 0건이었다.
- 정답 문서 "2026년도 중소기업 정책자금 융자계획 공고"는 코퍼스에 있고, 의미 검색으로는 상위에 잡힌다.

# Cause

붙여 쓴 복합어가 띄어 쓴 본문과 바이그램 경계에서 어긋나 어느 청크에도 안 맞고, AND라 전체가 0건이 된다.

- 키워드 검색은 `c.content &@~ :q`로 청크 본문을 매칭한다(`src/search/repository.py` `keyword`). 토크나이저는 TokenBigram, `&@~`는 공백 토큰을 AND로 묶는다.
- 질의 "중소기업정책자금"은 바이그램 "업정"(기업에서 정책으로 넘어가는 경계)을 요구한다.
- 본문 "중소기업 정책자금"은 공백에서 끊겨 "업정" 바이그램이 없다. 이 토큰이 어느 청크에도 안 맞는다.
- 다른 토큰 "융자계획"은 본문에 있지만 AND라 소용이 없다. 결과가 0건이 된다.

# Fix

아직 코드 수정을 적용하지 않았다. 진단만 마쳐 상태는 open이다.

- (권장, 제안) 토크나이저를 형태소 기반(TokenMecab 등)으로 바꿔 복합어를 분해한다. 붙여 쓴 "중소기업정책자금"과 띄어 쓴 "중소기업 정책자금"이 같은 토큰으로 맞는다.

  바이그램 대 형태소 비교(질의 "중소기업정책자금", 본문 "중소기업 정책자금"):

  | 방식 | 질의 토큰 | 본문 토큰 | 매칭 |
  | ---- | ---- | ---- | ---- |
  | 바이그램 | 중소, 소기, 기업, 업정, 정책, 책자, 자금 | 중소, 소기, 기업, 정책, 책자, 자금 | "업정" 없어 실패 |
  | 형태소 | 중소기업, 정책, 자금 | 중소기업, 정책, 자금 | 같은 토큰이라 매칭 |

- (제안) 형태소로 바꾼 뒤 미등록어(고유명사, 신조어) 재현율이 아쉬우면 형태소 색인과 바이그램 색인을 함께 두고 OR로 검색한다. 형태소가 못 잡는 미등록어를 바이그램이 받친다.
- (제안) AND 매칭을 OR과 관련도 스코어링으로 바꿔, 한 토큰이 안 맞아도 결과를 0으로 만들지 않는다.

  AND 대 OR 비교(질의 토큰 [소상공인, 정책자금, 융자]):

  | 문서 | 맞은 토큰 | AND | OR + 스코어링 |
  | ---- | ---- | ---- | ---- |
  | A | 소상공인, 정책자금, 융자 (3) | 통과 | 1위 |
  | B | 정책자금, 융자 (2) | 탈락 | 2위 |
  | C | 융자 (1) | 탈락 | 3위 |

  AND는 셋 다 맞은 A만 남기고, A가 없으면 0건이다. OR + 스코어링은 많이 맞은 순으로 A, B, C를 다 돌려줘 부분 매칭도 순위로 남긴다.

# Prevention

- 붙여쓰기와 띄어쓰기 변형은 바이그램 매칭을 깬다. 정규화하거나 형태소 토크나이저로 경계를 맞춘다.
